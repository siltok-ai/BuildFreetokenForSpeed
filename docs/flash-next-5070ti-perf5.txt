Changes
1. Publish protected expert ownership metadata on GPU after the original-byte
   exchange, rather than downloading five tables and re-uploading each layer.
   Zero extra dynamic slots are permitted because two full-layer prefill banks
   remain borrowable by decode. Existing budgets are not silently expanded.
2. Signed Q2 byte-permute decode retains original packed Q2 bytes, every expert,
   Q8 codes and FP32 activation scales. It eliminates integer offset correction.
   FP32 reduction layout changes: raw IDs differ from perf4, while frozen quality
   remains15/20 and thinking3/3 without added failed cases. The old vector kernel
   remains an independent numerical reference, with its byte-addressing contract.
3. Protected promotion can read an already-valid GPU dynamic copy of the incoming
   expert; the outgoing original bytes still return to its assigned compact host
   row. This adds no expert mirror and changes no total CPU/GPU bank ownership.
4. Optional ple_row_cache_rows (default0) is a bounded eight-way CPU row cache.
   The measured1,048,576-row IQ4_NL configuration uses102,891,520 bytes, saves
   raw row bytes and does not allocate VRAM or change math. Rows below8 or above
   16,777,216 reject, and the option requires the disk backend. Native capacity
   rounds down to complete eight-way sets. No unflushed resize is allowed.
