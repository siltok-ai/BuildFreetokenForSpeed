Useful next-profile candidates
The working source5 snapshot adds GPU publication of owner metadata after byte
exchange, avoiding five metadata downloads and repeated per-layer uploads. Its
zero-extra-dynamic-slot option is valid because the two prefill buffers are still
borrowed for decode. Thirteen GPU components plus two subtests, both modes'
15/20 non-thinking and 3/3 thinking, and state grow/shrink pass. Source-only
performance preserves all 17 long-run IDs per mode; gains alone are modest.
This source is still labelled perf4 internally and is not a distributable wheel.

The signed Q2 byte-permute prototype follows Strata Split<42>: decode -1/0/1/2
directly and eliminate integer correction dot products. Original compressed
weight bytes, all experts, FP32 activation scales and Q8 codes are retained.
The compiler's FP32 reduction layout changes, so outputs are not bitwise equal:
both quality suites preserve 25/27 IDs, and long-output IDs also change. Every
65536-code input / 524288 decoded values is checked exactly; twelve real expert
geometries and changed-route graph replay pass bounded numerical comparisons.
Both full-model modes retain 15/20 and 3/3 with no added failed cases and pass
state rebuilding. This is a numerical implementation change, not weight pruning.

Cached incoming promotion reuses an existing valid GPU dynamic copy while
writing the outgoing protected row to its original host slot. It preserves the
compact complement ownership scheme and RAM/VRAM budgets. About 80% of incoming
promotions can use that path; its additional ON throughput gain is about 0.5%.

Rejected / incomplete directions
The first native grouped kernel improves isolated cases but regresses the late
4K full run to70.668tps; it is not selected. GU-only native replacement retains
all output IDs but gives no overall gain. A Strata CPU expert implementation,
FP32 Q8 scales and valid compact host pointers were tested in a private FFI
module. An initial mapped-host merge bottleneck was diagnosed with Nsight and
fixed to read the already-device-resident route mask. Its three-language result
96.001/91.282/101.308 is still weaker than the GPU-only candidate; no hybrid
module is being shipped. Thread ownership, changed host owners and poisoned old
host rows are checked by component tests.
