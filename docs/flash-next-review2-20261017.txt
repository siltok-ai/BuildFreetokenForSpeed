Engine findings and candidate changes:
1. A Unicode stop character can use multiple byte-level tokens. A character-count tail
   misses complete stops such as two unicorn emoji or supplementary CJK characters.
   Bound the output-only decode suffix by UTF-8 bytes instead of code-point count.
2. Multiple stops within one token previously selected list order. Select the earliest
   position in decoded output, retaining list order only for a position tie.
3. A valid large top_k overflows int32 during device sampling preparation. Keeping at
   least the vocabulary is unfiltered sampling; cap it before constructing device tensors.
4. Scheduler context clipping mutates shared SamplingParams, shrinking later prompts in
   offline batches. Create request-local dataclass replacements only when clipping is needed.

Speed-side findings are owned by Speed:
5. Fixed KV capacity was omitted from prompt preflight, accepting a prompt that leaves no
   room for any output and loading large weights before the inevitable request rejection.
6. ASGI 2.3 disconnect cancels an AnyIO scope, which repeatedly cancels cleanup awaits.
   The prior SSE tests mainly cover the ASGI 2.4 OSError path. Cleanup ownership flags
   could be set without executing cancellation/unsubscription. Protect the owned cleanup.
